# ERNI master template layout catalog

Use exact layout names when addressing layouts programmatically. Some names contain trailing spaces in the source deck; prefer substring matching when possible.

## Key layout families

| family | layouts | use |
|---|---|---|
| cover | Cover Layout 1, 2, 3 | opening slides; use Layout 1 only with an approved hero image |
| index | Index Layout 1a-1d, 2a-2d | agendas or tables of contents |
| section | Section Layout 1-4 | chapter dividers with large section number |
| info | Info Layout 1-10, Image and Text 6a/6b | narrative, pillars, full graphics, text with image |
| chart | Chart Layout 1a/1b, 2a/2b, 3 | icon-led comparisons and bullet groups |
| flow | Flow Layout 1-6 | process, journey, lifecycle, operating model |
| containers | Containers Layout | facts, figures, six boxes |
| people | People Layout 1-3 | team or profile slides |
| back cover | Back Cover 1-3 | contact and closing slides |
