## Image usage rules

- Use one dominant abstract image per slide unless a people/photo layout explicitly requires multiple images.
- Use images mainly as cover, section, full-graphic, or side-panel visuals; avoid using them as small decorative thumbnails.
- Crop to cover the placeholder without stretching. Preserve aspect ratio and avoid squashing.
- Add a white, ERNI blue, or subtle dark overlay only when needed for text contrast.
- Do not recolor images heavily. Let the template colors and typography carry the brand system.

## Template icon set

`assets/icons/template-media/` contains the extracted ERNI master icon and brand media from the uploaded template, including line icons for software, cloud, security, engineering, people, process, quality, certificates, location, and growth. Use these files in icon placeholders when the chosen layout expects icons. Keep icon color/style consistent; most are ERNI blue line icons.
